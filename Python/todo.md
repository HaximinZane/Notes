**如果按你目前的学习阶段排优先级，我会先抓住这条主线：**

**文件与路径 → JSON／CSV／配置 → 容器与迭代工具 → 异常与上下文管理 → 数据类与类型注解 → 命令行、日志和 SQLite → HTTP 请求与验证 → pytest → 并发。**
